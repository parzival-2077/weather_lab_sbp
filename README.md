# weather_lab_sbp

Лабораторная работа на языке программирования Python: автоматическое определение местоположения по IP,
получение прогноза погоды из OpenWeatherMap, агрегация 3-часовых интервалов в
дневные сводки, сохранение в SQLite через SQLAlchemy, экспорт в Markdown.

## Используемые технологии и API

- `requests` — HTTP-запросы
- `SQLAlchemy 2.x` — ORM для работы с БД
- `python-dotenv` — загрузка переменных окружения
- SQLite — база данных
- OpenWeatherMap Forecast API — прогноз погоды на 5 дней
- ipinfo.io — определение местоположения по IP

## Установка

```bash
git clone https://github.com/USERNAME/weather-etl-lab.git
cd weather-etl-lab
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка

1. Зарегистрируйся на https://openweathermap.org/ и получи бесплатный
   API-ключ в разделе https://home.openweathermap.org/api_keys.
2. Создай файл `.env` из шаблона:

   ```bash
   cp .env.example .env
   ```

3. Заполни `.env`: укажи `WEATHER_API_KEY`, при необходимости измени
   `GEO_API_FALLBACK_CITY` и параметры БД (`DB_URL`, `DB_USER`, `DB_PASSWORD`).

## Запуск

```bash
python main.py
```

## Структура проекта

| Файл | Назначение |
|------|------------|
| `main.py` | Точка входа, оркестратор ETL-контура |
| `geo_locator.py` | Определение города и координат по IP |
| `weather_client.py` | Запрос и агрегация прогноза из OpenWeatherMap |
| `db_models.py` | Модель SQLAlchemy и работа с БД |
| `exporter.py` | Экспорт данных в Markdown |
| `.env.example` | Шаблон конфигурации |
